# ZenShare Browser Privacy Shield

This optional Chromium-based browser extension blurs pages that look like login, signup, registration, password, or verification screens.

It is a practical privacy guard for screen sharing and recordings. The extension blurs the page in the browser itself, so it can help hide sensitive content from viewers.

## Install

1. Open Chrome or Edge.
2. Go to the extensions page.
3. Enable Developer Mode.
4. Load this folder as an unpacked extension.

## Notes

- This is optional and separate from the core ZenShare CLI.
- It applies to browser content only and does not change the desktop state managed by ZenShare.
